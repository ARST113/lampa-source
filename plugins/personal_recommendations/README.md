# Для вас — персональные рекомендации для Lampa

Расширение добавляет раздел **«Для вас»** с фильмами, сериалами и аниме. Использует уже существующую историю активного профиля Lampa: заново отмечать просмотренное не нужно. Работает на устройстве через штатный TMDB API Lampa; дополнительный сервер не нужен.

## Установка

1. Откройте настройки Lampa → **«Расширения»** и добавьте URL:

   ```text
   https://raw.githubusercontent.com/ARST113/lampa-source/main/plugins/personal_recommendations/dist/recommendations.js
   ```

2. Перезапустите Lampa и откройте **«Для вас»** в боковом меню.

Устанавливается только `dist/recommendations.js`. Node.js нужен только для разработки.

## Как пользоваться

- Кнопка фильтра в шапке переключает **«Всё / Фильмы / Сериалы / Аниме»**. Там же находятся обновление подборки, **«Мои оценки»** и **«О подборке»**.
- Длинное нажатие или правая кнопка мыши открывает обычное меню карточки. Выберите **«Нравится»**, **«Не интересно»**, **«Уже просмотрено»** или **«Почему рекомендовано»**.
- Убрать отзыв можно через **«Мои оценки»** или меню карточки. Обычное открытие карточки ведёт на стандартную страницу Lampa.

## Как строится подборка

Модуль читает историю, просмотренное, лайки, закладки и брошенные материалы, не изменяя их. Лайки влияют сильнее, история и закладки — слабее. Кандидаты приходят из рекомендаций TMDB, текущих трендов и подборок по любимым жанрам. Движок упорядочивает их по интересам профиля, оценкам зрителей, свежести и разнообразию; просмотренное, скрытое, adult и будущие релизы исключаются.

Аниме определяется как японская анимация: жанр TMDB «Анимация» и исходный язык `ja`. Отдельные запросы добавляют аниме-фильмы и сериалы даже при смешанной истории. Без истории доступна начальная подборка по популярности и рейтингу.

Для истории из других каталогов используются надёжные TMDB ID или сопоставление по IMDb ID. Материалы без соответствия пропускаются; исходные карточки остаются прежними.

## Профили и хранение

Подборка, кеш и отзывы разделены по аккаунтам и профилям. При смене профиля старые сетевые ответы отбрасываются. Новые отзывы расширения сохраняются **локально и не синхронизируются между устройствами**; действие «Уже просмотрено» не переписывает стандартную историю Lampa.

Кандидаты кешируются на **30 минут**. Новые исходные материалы или жанры обновляют подборку раньше; при сетевом сбое может использоваться сохранённая подборка. Расширение не проверяет доступность фильма у конкретного провайдера.

## Разработка

Нужен Node.js 18 или новее, установка зависимостей не требуется. Из корня клонированного репозитория:

```sh
cd plugins/personal_recommendations
node --test tests/*.test.cjs
node scripts/build.cjs
```

`src/engine.js` — ранжирование, `src/data.js` — история, TMDB и кеш, `src/plugin.js` — штатный интерфейс Lampa. Сборка объединяет их в `dist/recommendations.js`.
